# resnet34-vit-base-swin-tiny
Conducted a comprehensive comparison of ResNet34, Vision Transformer (ViT-Base), and Swin Transformer on MedMNIST OCT dataset for multi-class retinal pathology detection

## Dataset
The dataset used in this project is taken from Kaggle:
[MedMNIST: Standardized Biomedical Images](https://www.kaggle.com/datasets/arashnic/standardized-biomedical-images-medmnist)
